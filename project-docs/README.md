# Project Documentation — Zombie-World-RPG

Thu muc nay chua luu lai toan bo tai-lieu phan-tich va ke-hoach trien-khai cua du an.
Muc dich: sau khi chinh sua code, cap nhat tai-lieu day de khong can hoi lai va giu dong bo voi code.

## Cac file trong thu muc

| File | Noi dung |
|------|----------|
| `ARCHITECTURE.md` | Kien truc tong quat, entry point, state management, luu/load, routing |
| `GAMEPLAY-FLOW.md` | Luong choi tu dau den cuoi, gameplay loop, flow diagram (Mermaid) |
| `FEATURE-INVENTORY.md` | Danh sach toan bo tinh nang phan loai theo nhom (A-G) |
| `ROADMAP-PLAN.md` | Ke-hoach trien-khai 4 giai doi (Phase 1-4) |
| `CHANGELOG.md` | Ghi-nhat-ky cap nhat code (bat buoc ghi khi sua source) |

## Luat bat buoc (xem o goc repo)

Xem file `RULE.md` o goc repository. Moi lan chinh sua source code, bat buoc cap nhat `CHANGELOG.md` va (neu can) cac file tai-lieu lien quan.

## Cach su dung

1. Truoc khi sua code: doc `ARCHITECTURE.md` va `GAMEPLAY-FLOW.md` de hieu kien truc hien tai.
2. Khi sua code xong: ghi vao `CHANGELOG.md` (ngay thang, file sua, noi dung thay doi).
3. Neu sua thay doi cau truc, he thong hoac luong choi: cap nhat `ARCHITECTURE.md` hoac `GAMEPLAY-FLOW.md`.
4. Neu them/sua tinh nang: cap nhat `FEATURE-INVENTORY.md`.
5. Neu thay doi ke-hoach trien-khai: cap nhat `ROADMAP-PLAN.md`.
