# Quy tuc bat buoc cap nhat tai-lieu thiet-ke

Khi chinh sua source code trong du an Zombie-World-RPG, BAT BUOC phai:

1. Cap nhat file `project-docs/CHANGELOG.md` voi ngay thang, file da sua, noi dung thay doi.
2. Neu thay doi cau truc, he thong hoac luong choi: cap nhat `project-docs/ARCHITECTURE.md` va hoac `project-docs/GAMEPLAY-FLOW.md`.
3. Neu them/sua tinh nang: cap nhat `project-docs/FEATURE-INVENTORY.md`.
4. Neu thay doi ke-hoach trien-khai: cap nhat `project-docs/ROADMAP-PLAN.md`.

Muc dich: luu lai flow, kien truc de sau nay khong can hoi lai va giu tai-lieu dong bo voi code.
